# 学习一页纸（v3，2026-10-28）

英文版 / English: [learning-one-pager.en.md](learning-one-pager.en.md)

## 1. 定义

**学习是由经验引起的、相对持久的能力变化：撤掉支架之后，自己还能做、能判断、能用到新情况里。**

过程上，它是把**借来的判断**和**借来的动力**，一点点换成**自己的**。

## 2. 阶段与类型

**过程：大方向是线性的，实际路径不是。**

触发 → 启动 → 循环（每轮以一个小里程碑收尾，反复多轮）→ 检查点（深入 / 横移 / 停 / 重定）→ 达成 → 维护

- 线性的：从不知道到会的大方向；一层压一层的领域里的前置关系。
- 非线性的：一轮轮循环、平台期、突然的跳升、检查点上的回头。整体像螺旋：同一个东西隔一段再回来，每次更深。

**有意识 ↔ 无意识：是连续谱，交替出现。**

- 偏有意识：定目标、刻意练、对答案、检查点。
- 偏无意识：空档里的整合、熟练后的自动化、看到就会的迁移、说不出来的 taste。
- 节奏：有意识地准备 → 无意识地整合 → 有意识地回想检验。

**学到什么程度：每个知识点分别定，够用就停。**

- 深度：认得 → 讲得清 → 判断得了 → 做得出
- 连接：零散 → 连成整体 → 推到新领域
- 流利：要想 → 不用想

## 3. 为什么要分这些

为了知道每一刻该给什么支持，让一个普通人留在健康的学习状态里。

- **最危险的一段：判断力跑到能力前面。** 看得出好坏，自己还做不到，动机在这里最容易掉，很多人在这里放弃（Ira Glass 的"品味差距"）。
- **强自驱的人能靠动机撑过去，会自学的人会自己找验证点。普通人两样都缺。** 所以系统要先借出去：借判断（方向、证据、错题反馈），借动力（节奏、小里程碑、同伴、截止日期）；再逐步撤掉。
- 研究对应：外在动机可以一步步内化成自己的（自我决定理论的内化连续谱）；新手需要强引导，熟练后要放手（专长逆转效应）。

## 4. 通用设计框架：任何主题都能套

1. **先定终点和证据。** 把"想学 X"改写成一件能验证的任务；每个知识点定档，够用就停。
2. **从学习者的起点出发。** 先测已经会什么、什么能迁移，不重复教已经会的；多来源画地图，看领域结构选学法。
3. **循环里先让学习者试，错题是一等材料。** 难度保持在大部分做对、少部分做错；错题既标出能力的边界，也是最好的练习。
4. **小里程碑要密，而且要真。** 每隔一小段，撤掉支架测一次"不靠提示能做什么"。奖励绑在能力上，不绑在活跃度上。
5. **先借动力，再撤掉。** 节奏、提醒、同伴、截止日期先借出去，奖励和紧迫感要平衡；能力看得见以后，换成学习者自己选的目标和成就感。
6. **盯信号，提前进检查点。** 跳过、平台期、错误率不降、动机掉，都是信号：改目标、换形式、加同伴，不要等到放弃。
7. **AI 的位置。** 出题、反馈、追问、汇总、唱反调；不替学习者做尝试，不一味顺着说。
8. **达成看真实任务，之后维护。** 在没见过的情境里做到；低频回想，易变的部分定期刷新，不需要的允许放下。

## 案例：用这个框架看多邻国

| 做到了 | 没做到 |
|---|---|
| 开始门槛极低，每天固定节奏，小成就很密 | 奖励绑在活跃度上（经验值、连续天数），不在能力上 |
| 间隔重复有算法支撑（half-life regression，上线后日活跃 +12%） | 动力一直是借来的，没有设计"撤掉"这一步 |
| 把动力借给你：连续打卡、排行榜、提醒 | 练习多是识别和选择，撤掉支架的产出少；口语效果缺独立证据 |
| 读和听可达大学第四学期水平（Jiang et al. 2021，作者含 Duolingo 研究员） | 起点和迁移考虑少（作者的体验：中文母语者学日语仍要从汉字学起） |
| | 终点不是真实任务，也没有检查点上的重新决定 |

**一句话诊断**：多邻国把借动力做到了极致，判断却只借到"认出来"这一档；它没设计撤掉支架这一步，所以动力停在打卡，能力停在识别。
