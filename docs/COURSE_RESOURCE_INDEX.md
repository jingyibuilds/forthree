# Course Resource Index

This is the working map for public course references. It is not a link dump.
Lesson links should come from this index only after the exact page/video has
been reviewed and matched to a learner need.

## Rules

- Course-level source: useful for provenance and curriculum shape.
- Lesson-level resource: useful at one exact moment in the learning flow.
- "Authoritative" is not enough. The page must help the learner think the next
  thought with less confusion.
- External resources are optional by default. Required external work needs
  completion tracking and a return-path design.
- Link out to the original page. Do not copy, embed, screenshot, or rehost
  external course material unless license and attribution have been reviewed.
- Study source trails, not just landing pages. If a syllabus points to readings,
  instructor notes, companion repositories, or textbooks, index those materials
  too when they affect sequencing, density, explanations, or exercise design.
  The deeper study is for curriculum judgment; learner-facing content remains
  original.
