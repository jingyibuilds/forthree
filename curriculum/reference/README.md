# Reference programs

The programs behind the "Measured reference" panes and the worked answers the
content quotes. They are **not served** — nothing under `curriculum/` is — and
they exist so that every number the content states is produced by a program
that `scripts/measure-content.mjs` runs (`docs/LESSONS.md` L-AUTH-02).

One folder per part. A reference that needs a lab's data loads it from the
kit in `public/labs/`, so the kit stays the only copy of the data.
