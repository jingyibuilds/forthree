# What changed

Newest first. Each entry is one release of the course, cut from a tagged
version of the private line where it is written.

## v2 — 2026-11-13 — sessions 1–3, and a trial you can open in a browser

**New: the web trial.** The same course, the same deterministic checks, with
no account and no server-side storage — your progress is kept in your own
browser and travels with each request. It opens on a page that says what the
course is and why it is one line rather than a library, then starts session 1.
It cannot run the labs, because those need a terminal and the course's own
Python, so a lab there shows its commands and lets you past, marked *not run*.
Three buttons save your progress to a file, load one back, or start over.

**Changed: sessions 1–3 were rewritten.** Every session now states what you
will be able to do at its end before it asks anything, every task names what
teaches it, and each part keeps a reading log — a tick per reading and a note
per session, on one page.

**Known limits.** The AI margin notes are still fixed text: no model is
called, here or locally. The web trial keeps nothing on a server, so clearing
your site data ends that run; save the file if you want to come back to it.
Sessions 4–21 are not published.

Cut from `public/v2` of the private line.
